# Statistical Analysis Summary

## 1. Introduction
Statistical analysis helps us understand the dataset by calculating important statistical measures such as mean, median, variance, and standard deviation.

## 2. Dataset Information
- Dataset Name: Breast Cancer Wisconsin Dataset
- Total Records: 569
- Total Features: 30
- Target Column: diagnosis

## 3. Statistical Measures

1. **Mean:** The average value of all observations.
2. **Median:** The middle value of the sorted data.
3. **Variance:** Measures how much the data values are spread out.
4. **Standard Deviation:** Measures the variation of values from the mean.

## 4. Data Distribution Analysis

- Histograms were created for Mean Radius and Mean Texture.
- A boxplot was created for Mean Radius.
- Histograms helped understand the frequency and distribution of values.
- The boxplot helped identify the spread and possible outliers.

## 5. Dataset Splitting

The dataset was divided into:
- Training Data: 70%
- Validation Data: 15%
- Testing Data: 15%

Stratified splitting was used to maintain class distribution.

## 6. Conclusion

Statistical analysis helped understand the numerical features of the dataset. Data visualization provided information about distributions and possible outliers. The dataset was also divided into training, validation, and testing sets for reliable future model evaluation.
