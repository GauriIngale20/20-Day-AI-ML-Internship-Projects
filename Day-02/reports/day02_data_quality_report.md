# Day 02 – NumPy and Pandas Foundations

## Project Summary: Employee Data Quality Analysis

The objective of this task was to learn NumPy and Pandas and perform data analysis on an employee dataset.

### Work Completed
1. Loaded the employee dataset using Pandas.
2. Inspected the dataset using `head()`, `info()` and `describe()`.
3. Identified missing values and duplicate records.
4. Checked and corrected data types.
5. Handled missing and invalid values.
6. Removed duplicate records.
7. Filtered employee data based on conditions.
8. Grouped employees department-wise.
9. Joined DataFrames using the `merge()` function.
10. Generated summary statistics.
11. Exported the cleaned dataset into CSV format.
12. Created a Data Quality Summary Report.

### Tools and Libraries
- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

### Final Deliverables
- `data_quality_analysis.ipynb` – Complete analysis notebook.
- `employees.csv` – Original dataset.
- `cleaned_employees.csv` – Cleaned dataset.
- `data_quality_summary.md` – Data Quality Summary Report.

### Learning Outcome
Learned how to load, inspect, clean, filter, group, merge, summarize, and export tabular data using NumPy and Pandas.
